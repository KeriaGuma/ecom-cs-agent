# 用户发图片测试集：生图提示词

这份文档给 `eval/e2e_image_test.jsonl`（任务 e2e-img01～e2e-img30）准备图片，共 30 张，文件名 t01.jpg～t30.jpg，和任务一一对应。

## 使用说明

1. 把每一节代码块里的提示词整段复制，粘贴到 GPT 里生成图片。每张图单独开一次生成，不要把多条提示词合在一起。
2. 生成后保存到 `eval/images/test/`，**文件名必须和本节标题里的一致**（如 `t01.jpg`）。jpg 或 png 都可以；如果存成 png，文件名主体保持一致（`t01.png`），并相应修改 jsonl 里的扩展名。
3. 对照每节的“生成后必须能看到的要点”检查。**要点没画出来就重新生成**，可以在原提示词后面补一句强调，比如“裂纹一定要清楚可见”。
4. 目标是像真实用户用手机随手拍的照片，不像广告图。生成结果太精致（纯色背景、棚拍光、完美居中）时也建议重新生成。
5. 带文字的图（t25～t28）要逐字核对文字，有错字、乱码或缺字都要重新生成。
6. 第 21 题的第二轮复用 t01.jpg，不需要额外的图。
