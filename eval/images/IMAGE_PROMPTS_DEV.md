# 图片识别开发集：生图提示词（20 张）

这一组图片用来调视觉模型的提示词和流程，可以反复使用。测试集在另一份文档里，由看不到系统提示词的人单独编写。

## 使用说明

1. 把每条提示词完整粘贴给 GPT 生成图片。一张图开一次对话效果更稳定。
2. 保存到 `eval/images/dev/`，**文件名必须和标题一致**，比如 `d01.jpg`。jpg 和 png 都可以，扩展名不一致也没关系，程序会按编号找。
3. 生成后对照“必须能看到”检查一遍。要点没画出来，比如裂纹太淡、文字写错，就重新生成。宁可多生成几次，也不要用不符合要求的图，因为评测的标准答案就是按这些要点定的。
4. 如果 GPT 加了水印或说明文字，请重新生成。

**实际生成方式**：用 `python -m cs_agent.gen_images` 调阿里云百炼的文生图接口（默认 qwen-image-3.0，免费额度用完自动换下一个模型），提示词原样使用、不做改写。生成后逐张核对要点，不合格的重新生成（d08、d19 生成了几版，挑要点最清楚的一版）。生图模型不肯把主体拍糊，所以 d04 是生成后加了高斯模糊（`--blur d04=18`），每张图的模型和处理方式记在 `dev/_manifest.json`。

所有图片都要像**用户用手机随手拍的照片**，不要像商品广告图。下面每条提示词里都写了这一点，不用另外再加。
